# Phase 3 — Documentation Accuracy, Redundancy & Drift
**Scope: documentation review in small, thematic batches.**

1. Read master protocol, own progress/inventory/authority maps; choose a bounded batch of 2–5 related documents, *fewer for long documents*.
2. Read actual relevant passages and compare related specifications. Track complete versus partial coverage per file and lines.
3. Identify: contradictions; repeated or verbose requirements; ambiguous or untestable wording; stale/superseded guidance; `[Proposed]` promoted to `[Decided]`; unapproved simplification or additions; missing source of truth; misaligned visual or gameplay descriptions.
4. Append evidence-backed, uniquely numbered `DOC-...` findings to own `FINDINGS.md`. Recommend succinct wording without losing nuances; mark approval needed for changes that might alter meaning.
5. Update own `PROGRESS.md` and inventory coverage; reread output and stop after the batch. Do not assert entire phase complete unless every intended document is covered or explicit limitations are recorded.
