## **Observations**

### Large File Handling
The audit tool has a 10MiB limit for file reading, but the game contains large meshes that may exceed this. User requested increasing cap to 50MiB - this is an MCP/tool limitation that needs external configuration change. Large mesh files will need alternative inspection methods (e.g., reading in chunks via Python).

### "Terrain Runtime Generator Speed" Clarification
This refers to:
- **Generator speed** = time to pre-bake tiles on server (done once after terrain design is perfect)
- **Client block generation speed** = runtime voxel generation for client cache

The design intent: generator pre-bakes tiles → server builds giant cache of blocks → clients receive premade blocks + player edits.

### Tree Meshes
Currently procedural leaf cards; moving to actual 3D meshes. Tree LOD format document defines the schema before art production begins (per `ARCHITECTURE_BUDGET.md`).
