Install

  1. Open the zip and take out DynastySetup-{{BUILD}}.exe (right-click the zip, Extract All).
  2. Run it. If Windows says Windows protected your PC, click More info, then Run anyway. The game is not signed yet, so Windows does not know it.
  3. It installs just for you, with no administrator needed, and adds Dynasty to the Start menu.

Play

  • On the server page, the first row is Hannibal's House (hannibalshouse.duckdns.org). Pick it and press Join. If it asks for a password, use the one Dave sent you.
  • Everyone plays on the same build. When a new one is out, install the new game before joining: the old one cannot join and will say so. Install it over this one. Each new build is a new world: everyone starts again with an empty pack.

Report

  • Use Submit a bug or Suggest an idea on the home page.
  • The build is filled in for you. Attach your game log if you can: %APPDATA%\Godot\app_userdata\Dynasty a life well lived\logs\godot.log
  • A list of everything that felt wrong helps as much as one big report.
