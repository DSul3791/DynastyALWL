Install

  1. Open the zip you downloaded and take out DynastySetup-{{BUILD}}.exe (right-click the zip, Extract All).
  2. Run DynastySetup-{{BUILD}}.exe.
  3. Windows will probably show a blue box, Windows protected your PC. The game is not signed yet, so Windows does not know it. Click More info, then Run anyway.
  4. It installs just for you (no administrator needed) and adds Dynasty to the Start menu. At the end you can start it right away.

A new build: download it and install it over the old one. Your characters are kept. Everyone must be on the same build to play together.

Join the game

  • On the server page, the first row is Dave's server, Hannibal's House (hannibalshouse.duckdns.org). Pick it and press Join.
  • If it says Needs update, a newer build is out: download it from this page.

Tell us what you find

  • Bugs and ideas go on GitHub (free account needed): report a bug or an idea. There is no reporting from inside the game.
  • Put the build number ({{BUILD}}, also on the title page) in the Build box.
  • Drag in your game log: %APPDATA%\Godot\app_userdata\Dynasty a life well lived\logs\godot.log
  • A list of everything that felt wrong is just as useful as one big report.

Uninstall: Windows Settings > Apps > Dynasty > Uninstall.
