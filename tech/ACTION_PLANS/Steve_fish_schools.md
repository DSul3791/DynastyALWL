# Action plan C: fish school module (owner Steve, branch claude/steve-fish-schools, RESTART)
Design: design/FISH_AND_FISHING_PLAN.md section 2 and 4 (FINAL, Dave YES x5). Stacks on plan B (claude/steve-fish-classifier 566639af, water_kind_at); merge order R1, B, C. Nothing placed because it is near spawn: schools follow the water only.
1. Goal: a school is a computed record (cell, species, size, centre, radius, drift), never an entity, never saved. The server can ask "which school is near this point, and how close?" so a cast or a net haul gets the school factor (1.0 inside the radius, 0.5 within 2x, 0.15 outside; still possible, so no dead water).
2. Files: new src/server/server_fish.gd (pure, takes water_kind_at as a callable, no tile access); data/items/fish_schools.json (schools per cell 0-3, radius 3-8 m, drift metres and period, per-kind species weights, salmon season, sea cells larger, factor numbers); hook in server_items.gd: `_fish_chance` multiplies by the school factor at the cast point and `_net_haul` uses it; species comes from the school (fallback to today's `_fish_species(cell)` when a cell has no school).
3. Method: for each 128 m cell, hash(cell, slot, game day) gives 0-3 schools; each picks a centre by hash, accepted only if water_kind_at there is a kind the species lives in (up to 6 tries, else no school, so none ever lands on dry ground); species by kind: brook trout, river trout (+ salmon in autumn only), lake perch/carp/pike, pond carp/perch, sea shallow herring/mackerel (summer). Species names come from fishing.json "species_by_kind" if Sal's plan A has it, else a small table in fish_schools.json (one place, said in the notes). Drift: centre = base + smooth function of (hash, game time), each step re-checked with water_kind_at and held at the base if it leaves its water kind. Salmon centre moves upstream during the autumn run along the river class only.
4. Stock link: school size = share of the cell's existing hidden stock (fish_stock(cell)); catching still removes from the stock as today, so schools shrink and vanish at 0 and come back with regrowth. Sum of school sizes never exceeds stock.
5. Cost: computed on demand (a cast, a haul), cached per cell per game day, 2000 entries max; no per-tick work, so zero cost with nobody fishing. Target under 0.05 ms per cast.
6. Tests (headless, test_fish_schools.gd, same made-up map probe as test_fish_water.gd): deterministic (same cell and day, same schools); every school and every drift step is on water of an allowed kind; stock conservation; salmon only in autumn and only in river; factor 1.0/0.5/0.15 by distance; empty-water cell has none; cost. Plus local_check 233, parse_scan.
7. Out of scope: jump event and splash (D, E), catch methods bow/spear (G), new fish items (F).
Risk: low; additive, falls back to today's behaviour with no school. CHANGE_LABEL RESTART.
