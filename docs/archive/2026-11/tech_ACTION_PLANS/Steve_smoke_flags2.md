# Action plan: early-game smoke flags --cook, --sleep, --snare (branch claude/steve-smoke-flags2)

Mike's Windows smoke needs no key presses. Same pattern as --shoot / --place-foundation (terrain_client.gd flag + inventory_view.gd run_*_test, prints "COOK TEST ..." lines ending PASS or FAILED), built on generator-v2 after the traps and rough-bed merges. RUNTIME (client test code only, no protocol, no server change; admin gives only).
Common: a helper `_wait_for_pack(number, count, resend_after_s)` (poll 0.5 s up to 15 s, resend the admin give once at 8 s) used by all five flags so they stop failing on a cold join.
1. --cook: admin give clay_hearth_kit + raw_meat + a stick or two; place the hearth 3 m ahead (ACT_PLACE); light/feed it as the game needs (admin give firewood, ACT_PLACE of a fire); cook with ACT_COOK at the hearth (the recipe path the cooking stations use); eat the result (ACT_EAT) and PASS when the raw item is gone, a cooked item appeared, and hunger rose. FAILED text names the step that did not happen.
2. --sleep: give rough_bed_kit, place it 2 m ahead under cover only if a roof exists (otherwise it tests the open-ground rule and says so), walk onto it, lie (ACT_STANCE 3), sleep (ACT_SLEEP 1) for 6 s, wake (ACT_SLEEP 0). PASS when the sleeping flag came back on the strain message and energy did not fall.
3. --snare: give snare (+ twine/stick if the recipe is by hand), place it (ACT_PLACE), admin-spawn a rabbit beside it, wait up to 90 s of 5 s polls (the server check is every 30 s; base chance is raised by an admin knob traps.json test_chance or, if Tyler prefers no knob, we wait up to 3 minutes), then look for a carcass world row within 2 m. PASS on the carcass; the printed lines include the server log "snare caught". Needs the admin spawn-animal action; if none exists I add `ACT_ADMIN_SPAWN_ANIMAL` ONLY if Tyler OKs a protocol number, otherwise the flag uses an animal that is already near and says "no rabbit near" instead of FAILED.
Tests: parse_scan, merge_check, check_controls; David3 runs each flag headless on the box; Mike on Windows.
