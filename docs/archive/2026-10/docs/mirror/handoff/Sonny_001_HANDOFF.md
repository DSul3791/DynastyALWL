- Overwriting tiles or water files in the working tree for a test is blocked by the permission classifier: always work on a scratch copy and use `--world=`.
- Commit your work before switching branches; a `git checkout <branch> -- file` lost an edit once (recovered from a dangling stash).

- Water files: a tile file's last row/column is its neighbour's first (shared 1921-sample edge); edge match compares them; a scratch bake of only some tiles fails edge match against old neighbours (expected).
- Falls are found server side from fall_levels (includes thin films of the baked channel); width logic in water_falls.gd `_river_width`.
- Static emulation of the live fall list headless shows no falls; use the real server run for fall checks.
