# Dynasty — agent entry point
Fetch current `origin/dev` and read this file there before starting a scoped task branch. PRs target `dev`; `main` promotion follows the approved release gate.

Read the four rulebooks for the assigned work:
- `docs/ai-team/CONSTITUTION.md`: authority, autonomy, approvals and provenance.
- `docs/ai-team/WORKFLOW.md`: assignments, branches, commands, checkpoints and retirement.
- `docs/ai-team/TEST_GATES.md`: risk-based tests, independent review and evidence.
- `docs/PONYTAIL_RULES.md`: engineering method and technical safeguards.

Use `docs/DOC_MAP.md` for topic designs and the current mission's state/decisions for scope. Load specialist references only when needed. Installed agent/skill definitions route to these authorities. Report actual SHA and observed results; short updates to Dave, durable evidence in task state. Historical installation records, handoffs and redirects are not additional rulebooks. `AGENTS.md` is intentionally omitted from this repo to avoid competing instructions.
